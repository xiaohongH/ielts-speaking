Part 3 答题小贴士
  • 深入论述 — Part 3 考的是展开能力：观点 + 原因 + 例子，别只给一句话。
  • 认题型 — 卡片上的标签（是什么 / 原因 / 对比 / 利弊 / 展望未来 / 你怎么看 / 方法）提示了答题结构。
  • 用连接词 — For example, However, As a result, Although, On the other hand… 让逻辑更清晰。
  • 记词汇和句型，别背整段 — 卡片背面的 vocab 是可迁移到多个话题的地道表达。
  • 给平衡的个人观点 — 结尾用 So I'd say… 收束，考官想听自然、真实的回答。
